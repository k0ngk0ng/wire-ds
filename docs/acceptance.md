# ChatDeepSeek 验收约定

最终范围：macOS 桌面应用、可配置全局快捷键、快速窗口与完整窗口、官方独立登录窗口、持久化登录、官网聊天体验、菜单栏与设置、可安装构建与可复现验证。

先编写此场景清单与 E2E 测试，再实现应用。自动化在真实 Electron 进程中操作界面；本地站点仅代替不受控制的 DeepSeek 服务，不模拟 Electron 的窗口、设置、持久化或快捷键注册。官方站点另做联网验证；真实账号、验证码和第三方服务可用性不能由本地站点测试证明。

| 场景 | 预期与失败处理 | 证据 |
| --- | --- | --- |
| 首次启动 | 展示官方登录窗口；不重写认证、不收集密码 | E2E：独立窗口、受限网页权限 |
| 登录完成与过期 | 同一个网页视图移至聊天窗口；过期时返回登录窗口 | E2E：视图标识与导航 |
| 退出并重启 | 官方会话、设置持久化；服务端失效时重新登录 | E2E：Cookie/localStorage、磁盘设置 |
| 全局快捷键 | 默认 F2，可录制功能键与组合键；注册失败保留旧值 | E2E：真实注册、UI 配置、冲突进程 |
| 快捷键呼出 | 隐藏时显示，后台时置前，前台时收起；聚焦输入框 | E2E：窗口状态；系统实机复核 |
| 呼出后的焦点 | 窗口激活、输入框就绪后执行 focus；用户主动操作、网页弹层和隐藏窗口优先 | E2E：延迟挂载、无鼠标点击、主动切换焦点与后台刷新；系统实机复核 |
| Thinking | 新出现的思考区域点击一次折叠；已折叠区域保持原状态；手动展开后尊重选择，回答继续流式显示 | E2E：流式输出、重复提问、手动展开；官网结构复核 |
| 快速与完整窗口 | 同一网页、草稿、滚动位置、流式回答不中断 | E2E：切换前后实例、内容与尺寸 |
| 自适应高度 | 快捷窗口初始 740 × 360，连续平滑地向下增长，保持上沿位置，到屏幕底部或高度上限后滚动；新对话恢复；完整窗口不自动改变 | E2E：原生窗口尺寸轨迹、流式增长、屏幕边界、模式中断与新对话 |
| 侧边栏 | 快速模式默认折叠；完整模式尊重官网行为 | E2E：操作官网适配入口；联网复核 |
| Esc | 中文组合输入与网页弹层优先，之后收起窗口 | E2E：弹层、输入法组合事件 |
| 新对话 | 优先识别官网控件的可访问名称、提示和同源新对话链接；无可靠入口时回到官网首页，不依赖固定图标；呼出行为可选继续或新建 | E2E：语义识别、改版兜底、登录保留与焦点 |
| 多屏/全屏 | 在鼠标所在屏幕有效区域呼出，屏幕移除时回到可见范围 | 系统实机复核，记录环境 |
| 生命周期 | 关闭隐藏、菜单栏重开、单实例、明确退出释放快捷键 | E2E：生命周期与第二进程 |
| 加载失败/断网/崩溃 | 显示错误与重试；不清空登录和设置 | E2E：真实请求中断、恢复 |
| 设置损坏 | 恢复安全默认值，保留损坏文件供排查 | E2E：磁盘文件损坏 |
| 设置窗口 | 固定标题栏和拖动区域，仅内容区滚动；禁止调整大小、最大化和全屏 | E2E：滚动前后标题栏位置、原生窗口能力与截图 |
| 应用更新 | 从 GitHub Releases 检查稳定版本；点击一次下载、校验、安装并自动重启；失败保留原应用并可重试 | E2E：版本比较、真实下载校验、原生安装、退出重启与回退 |
| 页面权限 | 无 Node、本地文件与 IPC 权限；外链交系统浏览器；权限按操作询问 | E2E：隔离、IPC 来源、导航 |
| 附件/下载 | 官网选择文件；下载经原生保存对话框，不自动保存到任意目录 | 联网或原生对话框复核 |
| 主题/置顶/开机启动 | 设置即时生效；开机启动仅在用户开启后注册 | E2E：主题、置顶；系统选项复核 |
| 官网改版 | 适配失败仍能使用完整原始网页；菜单提供重新加载与官网入口 | E2E：无适配元素的页面 |
| 安装包 | ARM64 app、DMG、ZIP；可复现构建；签名状态明确 | 构建日志、校验和、包启动验证 |

产物存放在仓库内：`artifacts/`、`test-results/`、`playwright-report/`、`release/`。测试数据与缓存放在 `.runtime/` 和 `.cache/`。不得使用真实账号信息填充测试报告。

新对话适配需覆盖以下失败场景：按钮文字或图标变化、名称来自 ARIA 引用或提示属性、嵌套的可聚焦容器误匹配、隐藏或禁用控件、回答中的同名链接、外站链接、入口完全缺失、点击后未切换会话、已处于新对话首页，以及未登录页面。兜底导航须保留登录状态，重新聚焦输入框；已处于首页或未登录时不刷新页面。

更新功能先覆盖以下失败场景：当前版本或旧版本误报更新、草稿与预发行版本、版本号或响应格式无效、对应系统与架构的安装包缺失、来源或文件名不匹配、SHA256 缺失、网络错误与 GitHub 限流、重复检查或下载、HTTP 下载失败、传输中断、长度或校验不匹配、已下载文件被修改，以及准备自动安装失败。失败不得退出原应用，未完成的下载须清理，之后可重试。应用内更新 E2E 使用本地 HTTP 服务提供 Release 元数据与安装包，版本选择、下载、磁盘写入及 SHA256 校验运行在真实 Electron 主进程中；安装请求先记录路径，由独立原生安装 E2E 再验证真实应用替换、重启与失败恢复。

平滑扩展需覆盖以下失败场景：内容突增时直接跳到最终高度、流式输出反复重启动画、虚拟列表或思考折叠造成窗口来回缩放、靠近屏幕底部时上沿漂移、切换完整窗口或关闭自动高度后旧动画继续运行、隐藏窗口仍持续调整、新对话未立即恢复最小高度，以及系统减少动态效果设置未被尊重。仅增高时使用动画，缩小时直接调整。测试记录真实原生窗口的尺寸和时间，产出可复跑的 JSON 轨迹与截图。

自动安装还需覆盖：安装目录不可写、安装包不完整、应用标识或版本不匹配、辅助进程无法启动、旧进程未退出、替换文件失败、安装器异常退出、新进程启动失败或未确认启动，以及更新过程中登录数据或设置丢失。先完成下载及预检，并确认辅助进程就绪，再退出旧进程；在独立目录验证真实应用替换、自动重启和失败回退，所有测试应用及数据位于仓库内，不触碰本机正式安装。保留 JSON 状态记录、安装日志与截图。
