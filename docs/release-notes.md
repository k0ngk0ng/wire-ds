ChatDeepSeek v1.0.9

- 更新检查改为公开的 `releases/latest` 跳转与 Release 校验文件，不再调用 GitHub REST API，无需 GitHub Token。
- 保留 SHA256 校验、安装包大小限制和「更新并重启」流程，更新后保留登录及设置。
- 原生安装测试结束时强制回收重启后的测试进程，避免留下测试窗口。
- macOS 更新前校验应用签名、标识和版本；文件替换或新版本启动失败时自动恢复旧版。Windows 使用静默安装器更新，失败可恢复原应用。
- macOS 安装包区分 Apple Silicon（arm64）和 Intel（x64）。个人使用无需 Apple 开发者证书，首次安装请按 DMG 内的「首次运行说明.md」操作。
- Windows 使用 x64 `.exe` 安装包，支持选择安装目录。

安装包未做商业证书签名或 Apple 公证。macOS 使用 ad-hoc 签名，并附有仅处理该应用的本机安装脚本。校验和见 `SHA256SUMS-*.txt`。

v1.0.3 和 v1.0.4 需要通过原有入口手动安装这次更新一次；之后可直接点击「更新并重启」。v1.0.1 及更早版本需要从此 Release 下载并覆盖安装。安装目录需要可写，预检失败时会保留原应用并提示重试。
