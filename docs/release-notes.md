ChatDeepSeek v1.0.2

- 新增 GitHub Releases 更新入口。在设置或菜单中选择「检查更新」，下载对应系统和架构的安装包，SHA256 校验通过后可打开安装。
- 安装版启动后会在后台检查稳定版本，不自动下载或安装。
- 改善新对话快捷键的入口识别。官网按钮文字、图标或布局变化时，可自动回到新对话首页，保留登录状态并聚焦输入框。
- 修正开发模式下的应用版本显示，避免将 Electron 版本当作应用版本。
- macOS 安装包区分 Apple Silicon（arm64）和 Intel（x64）。个人使用无需 Apple 开发者证书，首次安装请按 DMG 内的「首次运行说明.md」操作。
- Windows 使用 x64 `.exe` 安装包，支持选择安装目录。

安装包未做商业证书签名或 Apple 公证。macOS 使用 ad-hoc 签名，并附有仅处理该应用的本机安装脚本。校验和见 `SHA256SUMS-*.txt`。

v1.0.1 及更早版本需要先从此 Release 下载并覆盖安装一次。退出旧应用后再安装，登录数据与设置会保留；之后可使用应用内的更新入口。
