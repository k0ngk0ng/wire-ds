ChatDeepSeek v1.0.4

- 快捷窗口随逐行输出连续、平滑地向下扩展；新的高度目标沿用当前运动速度，避免每行文字出现时跳动。
- 扩展时固定窗口上沿，达到屏幕底部或高度上限后改为内部滚动，不向上顶动窗口。
- 避免虚拟列表回收、思考区域折叠等临时排版变化导致窗口反复缩放；新对话平滑恢复紧凑高度。
- 切换完整窗口、关闭自动高度或隐藏窗口时停止尺寸动画；尊重系统「减少动态效果」设置。
- macOS 安装包区分 Apple Silicon（arm64）和 Intel（x64）。个人使用无需 Apple 开发者证书，首次安装请按 DMG 内的「首次运行说明.md」操作。
- Windows 使用 x64 `.exe` 安装包，支持选择安装目录。

安装包未做商业证书签名或 Apple 公证。macOS 使用 ad-hoc 签名，并附有仅处理该应用的本机安装脚本。校验和见 `SHA256SUMS-*.txt`。

v1.0.3 可从设置或菜单中的「检查更新」下载安装包。v1.0.1 及更早版本需要从此 Release 手动下载一次。退出旧应用后再安装，登录数据与设置会保留。
