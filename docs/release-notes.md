ChatDeepSeek v1.0.1

- DeepThink 思考区域出现后，自动点击官网标题折叠一次，仍可手动展开。
- 修复快捷键呼出后输入框偶尔未获得焦点的问题：窗口激活、输入框就绪后自动聚焦。
- macOS 安装包区分 Apple Silicon（arm64）和 Intel（x64）。个人使用无需 Apple 开发者证书，首次安装请按 DMG 内的「首次运行说明.md」操作。
- Windows 使用 x64 `.exe` 安装包，支持选择安装目录。

安装包未做商业证书签名或 Apple 公证。macOS 使用 ad-hoc 签名，并附有仅处理该应用的本机安装脚本。校验和见 `SHA256SUMS-*.txt`。
